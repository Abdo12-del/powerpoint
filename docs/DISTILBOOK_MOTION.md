## 2. الفلسفة: خط زمني حتمي (Motion Canvas Style)

كل المشاهد **طبقات ماركب ثابتة بلا حركة ذاتية** — الماركب `data-*` فقط،
و`buildDistilbookTimeline` هو من يملك الزمن بالكامل:

- **Seek حرفي**: اسحب شريط الزمن أو اضغط فصلاً — كل إطار يُحسب من الزمن وحده.
- **بلا useEffect حركة**: لا تضارب مع StrictMode ولا تسريبات مؤقتات.
- **حتمية قابلة للاختبار**: نفس الزمن = نفس الإطار دائماً.

```
Scene (ماركب ثابت) ──► buildDistilbookTimeline ──► GSAP Timeline (paused/repeat)
        ▲                        │
        └── data-scene/data-* ───┘
```

### البنية

```
src/distilbook/
├── types.ts               # المشاهد السبعة، الإعداد الافتراضي، الهوية، شبكة المراجع، sceneAt
├── timeline.ts            # الخط الزمني الرئيسي: انتقالات + كوريغرافيا + نبضات BPM
├── DistilbookShowreel.tsx # المكوّن: مسرح + HUD + تحكم (تشغيل/مسح/BPM/حلقة) + مقبض seek
├── effects3d/
│   └── DistillStage.ts    # مشهد التقطير: MorphBlob متقلص + بلورات + قطرات + BeatClock
├── scenes/                # 7 مشاهد ماركب ثابت (+ DropMark وSPARK_OFFSETS في shared)
└── lab/DistilbookLab.tsx  # صفحة ?lab=distilbook: شورييل + فصول + لوحة قصة + هوية
```

**خط أنابيب المشهد الثلاثي الأبعاد**: يُحدَّث فقط عندما يكون مشهداً فعّالاً
(`active === sceneId === 'distill' && playing`) — صفر تكلفة خارج نافذته.

## 3. تزامن الحركة مع الإيقاع

- `beat = 60 / BPM` — تُستعمل في: stagger شرائح الأفكار (`beat × 0.5`)، stagger أرقام الختام،
  ونبضات `[data-beat]` (قفزة `scale 1.04` yoyo كل نبضة داخل نافذة المشهد).
- مشهد التقطير يعمل بـ `BeatClock` حقيقي: كل نبضة = انفجار قطرات + وهج إضاءة + اقتراب كاميرا.
- منزلق الإيقاع 80–160 BPM يعيد بناء الخط الزمني **مع الحفاظ على موضع التشغيل**.

## 4. الاستعمال

### كشريحة/مكوّن

```tsx
import { DistilbookShowreel } from '@/distilbook';

<DistilbookShowreel
  config={{
    brand: 'DISTILBOOK',
    tagline: 'قراءة أقل · فهم أعمق',
    bpm: 124,
    ideas: ['سؤال البحث', 'المنهجية', 'النتائج'],
    summaryCards: [/* بطاقاتك */],
    stats: [{ value: '10×', label: 'أسرع في المراجعة' }],
  }}
  height="560px"
/>
```

### بمقبض تحكم كامل

```tsx
const ref = useRef<DistilbookShowreelHandle>(null);
ref.current?.seek(12.2);  // قفز لمشهد المراجع
ref.current?.play();      // تشغيل من الموضع
ref.current?.pause();
```

### الخط الزمني مباشرة (تخصيص عميق)

```ts
import { buildDistilbookTimeline } from '@/distilbook';

const { tl, destroy } = buildDistilbookTimeline(rootEl, {
  config: myConfig,
  loop: true,
  onTime: (t) => console.log(t),
});
tl.time(7.3); // أي إطار
```

**تخصيص القصة**: عدّل `DISTILBOOK_SCENES` (الأزمنة/الانتقالات/الألوان) أو مرّر
`config` — كل المحتوى (أفكار/بطاقات/أرقام/CTA) بيانات لا كود.

## 6. الأداء والملاحظات

- الحزمة كسولة (`?lab=distilbook` فقط) — لا تدخل حزمة العرض، وThree.js داخلها chunk مستقل.
- بلا WebGL: مشهد التقطير يعرض بديل CSS بنفس الاستعارة (`⬗ → ✦`) — والاختبارات خضراء في jsdom.
- حركات SVG عبر `attr` و`opacity` فقط (لا CSS transforms على عناصر SVG) — توافق كامل مع jsdom/SSR.
- `DistillStage.step(seconds)` تقدّم زمني حتمي للاختبارات ومعاينة الإطارات.
- التنظيف: `destroy` يقتل الخط الزمني ويمسح خصائصه؛ `DistillStage.dispose` يُتلف كل موارد WebGL.
