# تعليمات الوكلاء الذكيين

تُدار القواعد من مصدر واحد منظّم بواسطة [Ruler](https://github.com/intellectronica/ruler):

- **مصدر التعديل:** ملفات Markdown الموضوعية في `.ruler/`، مع إعداد الوكلاء في `.ruler/ruler.toml`.
- **المخرجات:** `AGENTS.md` (مشترك للوكلاء المتوافقين)، `CLAUDE.md`، و`.github/copilot-instructions.md`. هذه ملفات مولّدة ومتتبعة في Git كي تكون التعليمات متاحة مباشرة بعد الاستنساخ.
- **تحديث المخرجات:** شغّل `npm run ai:rules` بعد تعديل أي ملف مصدر. لا تحرر ملفات المخرجات يدوياً؛ ستُستبدل عند التوليد.
- **المهارات:** تبقى المهارات الحالية في `.agents/skills/` كما هي؛ لا توجد مصادر مهارات في `.ruler/skills/`، لذلك لا ينسخها Ruler ولا يستبدلها.
- **النطاق:** الإعداد يستهدف AGENTS.md وClaude Code وGitHub Copilot. بقية الأدوات التي تقرأ `AGENTS.md` تستفيد من القواعد المشتركة؛ يمكن توسيع `default_agents` لاحقاً إذا أضيفت أداة فعلية.

التقسيم الموضوعي الحالي: سير إعداد العرض، التنوع البصري، سياسة المكتبات، توجيه المذكرات، الحركة والمهارات، والجودة والسلامة. الأدلة التفصيلية تظل في `docs/` والمهارات في `.agents/skills/`، بدلاً من نسخها إلى ملف تعليمات ضخم.
