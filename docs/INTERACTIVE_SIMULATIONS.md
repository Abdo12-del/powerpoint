# حزمة المحاكاة التفاعلية

تضيف الحزمة مختبراً علمياً تفاعلياً يعمل داخل تطبيق العرض، بلا تنقّل إلى مواقع خارجية. تجمع واجهة React العربية RTL بين المشاهد ثلاثية الأبعاد المحلية بـThree.js وست تجارب 2D من BN Lab، إضافة إلى مشهد تصادمات مبني على Matter.js ومشهد تداخل موجي بـp5.js. تُحمّل المحركات والتجربة المختارة كسولاً، ولا يحتاج تشغيلها إلى API أو اتصال شبكي.

## المعاينة

شغّل التطبيق وافتح `/?lab=simulations` للوصول إلى المختبر المستقل. اختر المجال ثم التجربة من قائمة الاختيارات، وعدّل منزلقات المتغيرات. تتوفر الآن 12 تجربة: أربع محلية سابقة، وست من BN Lab (لورنز، البندول المزدوج، الشقين، Gray–Scott، كلادني، كبلر)، إضافة إلى تصادم Matter.js وتداخل موجي بـp5.js. الرسوم البيانية الرقمية تظهر للنماذج المحلية التي تحسب نتائجها، ولا تُعرض نتيجة رقمية مصطنعة لمحركات المشهد. أزرار التشغيل والإيقاف وإعادة التجربة تتحكم بالتشغيل؛ وفي تجربة المقذوفات يمكن سحب المشهد لتغيير زاوية الإطلاق.

## التضمين داخل شريحة

المكوّن متاح للاستعمال مباشرة في محتوى الشرائح:

```tsx
import { InteractiveSimulations } from '@/simulations';

// يضم المختبر كاملًا داخل مساحة الشريحة، ويبدأ بتجربة حركة المقذوفات
<InteractiveSimulations embedded initialSimulation="projectile" />
```

يمكن أن يكون `initialSimulation` أي معرّف في `src/simulations/catalog.ts` مثل `projectile` أو `lorenz` أو `doubleslit` أو `collision` أو `interference`. ويمكن استخدام المكوّن دون `embedded` كواجهة مختبر كاملة.

## إضافة تجربة

أضف تعريفاً إلى `src/simulations/catalog.ts` يتضمن المجال والعنوان واللون والمتغيرات. للمشهد ثلاثي الأبعاد المحلي أضف حسابه إلى `calculateResult` ومشهده إلى `SimulationScene.tsx`. للمحركات الخارجية أضف `engine` ومكوّن adapter إلى `EngineScenes.tsx`، واستخدم التحميل الكسول والتنظيف عند فك المكوّن. لا تعرض مؤشراً رقمياً إلا إذا كان محسوباً من نموذج واضح. أنواع التعريف والنتائج العامة مصدّرة من `src/simulations/index.ts`.

## النطاق والمنشأ

- **المحاكاة المحلية السابقة:** المقذوفات، حركية التفاعل، الانتشار عبر الغشاء، والموجة الجيبية؛ مشاهدها ثلاثية الأبعاد وتُحسب نتائجها محلياً.
- **BN Lab Simulations:** ستة نماذج 2D مستوردة حسب الطلب: لورنز، البندول المزدوج، الشقين، تفاعل Gray–Scott، أشكال كلادني، ومدارات كبلر. المصدر MIT، مثبت على commit ثابت `5ddf6d0`؛ تسميات الرسم داخل بعض النماذج الأصلية باللغة الإنجليزية، بينما عناصر التحكم في المختبر عربية. اختبارات ودقة النماذج هي ادعاءات المشروع مع نتائج منشورة وليست مراجعة علمية مستقلة.
- **Matter.js:** مشهد تصادمات أجسام صلبة 2D، محرك MIT عام لا يقدّم التجربة جاهزة.
- **p5.js:** مشهد تداخل موجي 2D مخصص للمشروع؛ المكتبة مرخصة LGPL-2.1.

نصوص تراخيص الاعتمادات الموزعة محفوظة في `public/licenses/` لتبقى متاحة مع ناتج النشر.

تُحمّل التجارب الإضافية عند اختيارها، وتبقى المشاهد محلية ولا تتطلب API. لم أضف PhET كاعتماد: هو كتالوج لمحاكاة مستقلة، وبعض مستودعات المصدر القديمة غير مدعومة. ولم أضف Scenery كحزمة: مستودعه يطلب استنساخ منظومة مستودعات PhET الشقيقة وبنائها معاً، ولا يُنشر كحزمة npm صالحة للاستخدام المباشر هنا. هذه نماذج تعليمية توضيحية؛ لا تمثل بديلاً عن القياس التجريبي أو الحسابات العلمية الدقيقة خارج الافتراضات المبينة في كل نموذج.
