# حزمة المحاكاة التفاعلية

تضيف الحزمة مختبراً علمياً تفاعلياً يعمل داخل تطبيق العرض، بلا تنقّل إلى مواقع خارجية. بنيت واجهة React باتجاه RTL، ومشاهدها ثلاثية الأبعاد مرسومة محلياً بـ Three.js. يعتمد التشغيل على معادلات محلية، ولا يحتاج إلى API أو اتصال شبكي.

## المعاينة

شغّل التطبيق وافتح `/?lab=simulations` للوصول إلى المختبر المستقل. اختر الفيزياء أو الكيمياء أو الأحياء أو الرياضيات، وعدّل منزلقات المتغيرات. يتغير المشهد والناتج والرسم البياني مباشرة. أزرار التشغيل والإيقاف المؤقت وإعادة التجربة تتحكم بالزمن، وفي تجربة المقذوفات يمكن سحب المشهد لتغيير زاوية الإطلاق.

## التضمين داخل شريحة

المكوّن متاح للاستعمال مباشرة في محتوى الشرائح:

```tsx
import { InteractiveSimulations } from '@/simulations';

// يضم المختبر كاملًا داخل مساحة الشريحة، ويبدأ بتجربة حركة المقذوفات
<InteractiveSimulations embedded initialSimulation="projectile" />
```

عرّف `initialSimulation` بإحدى القيم `projectile` أو `molecule` أو `cell` أو `wave`. ويمكن استخدام المكوّن دون `embedded` كواجهة مختبر كاملة.

## إضافة تجربة

أضف تعريفاً إلى `src/simulations/catalog.ts` يتضمن المجال، عنوان التجربة، اللون، ثلاثة متغيرات على الأقل، ثم أضف معادلة ناتجها في `calculateResult`. أضف مشهد العرض الموافق إلى `SimulationScene.tsx`؛ إدارة دورة حياة WebGL والتنظيف عند فكّ المكوّن تتم داخله. أنواع التعريف والنتائج العامة مصدّرة من `src/simulations/index.ts`.

## النطاق

- الفيزياء: حركة المقذوفات والسرعة والزاوية والجاذبية والمدى.
- الكيمياء: نموذج تعليمي لحركية التفاعل وتأثير الحرارة والتركيز والعامل الحفاز.
- الأحياء: نموذج انتشار جزيئات عبر غشاء خلية بحسب فرق التركيز والنفاذية.
- الرياضيات: موجة جيبية قابلة للضبط بالسعة والتردد وفرق الطور.

هذه نماذج تعليمية توضيحية؛ تطبيقات المختبر لا تمثل بديلاً عن القياس التجريبي أو الحسابات العلمية الدقيقة خارج الافتراضات المبينة في النموذج.
