# المعدات العلمية — معرض PNG داخل الشريحة

حلّ معرض **المعدات العلمية** محل مختبر المحاكاة التفاعلية السابق: لا صفحة
مستقلة ولا مسار `?lab=` ولا محاكاة — بل لوحة جانبية صغيرة ترتبط بالعارض
الحالي وتُدرج صور PNG شفافة في **الشريحة المفتوحة** أثناء التحرير.

الكتالوج الحالي: **65 صورة أصلية** في **10 فئات**، تغطي الأصول العامة
(الزجاجيات، الأدوات، الأجهزة، السلامة، التسخين) واحتياجات التخصصات العلمية
في الجامعات الجزائرية (الكيمياء، الفيزياء، الأحياء، الجيولوجيا، الصحة).

## الفتح والإدراج

- من شريط التحكم أسفل العارض: زر **«المعدات العلمية»** (أيقونة قارورة)،
  أو المفتاح `G` (و`ل` على لوحة المفاتيح العربية). الزر متاح على الشرائح فقط.
- اللوحة تبقى والشريحة ظاهرة: ابحث بالاسم أو بالكلمة المفتاحية أو بمعرف
  الأصل، عربيًا أو فرنسيًا، أو تصفح بالفئات العشر.
- **السحب والإفلات**: اسحب الصورة المصغرة وأفلتها في موضعها على الشريحة.
- **بديل اللمس ولوحة المفاتيح**: انقر الصورة (أو Enter عليها) فتُضاف إلى
  منتصف الشريحة، ثم اضبطها بأدوات التحرير.
- البحث لا يفرّق بين `burette` و`سحاحة` وبين `bécher` و`becher`: التطبيع
  يوحّد همزات الألف والتاء المربوطة والتشكيل، والحروف اللاتينية المشكّلة
  (`é è ê à ç î ô û`). البحث يشمل كذلك `asset.id` نفسه.

## التحرير

فتح اللوحة = وضع تحرير الشريحة الحالية:

- **تحديد**: انقر العنصر (أو ركّز عليه بـ Tab).
- **تحريك**: اسحبه بالمؤشر أو اللمس، أو بالأسهم (`Shift` = خطوة أكبر).
- **تحجيم**: مقبض الزاوية يحفظ نسبة أبعاد الصورة دائماً (الارتفاع مشتق
  من العرض ونسبة الأصل، فلا تتشوّه الصورة أبداً).
- **حذف**: زر × على العنصر المحدد، أو `Delete`/`Backspace`.
- **تراجع/إعادة**: أزرار اللوحة أو `Ctrl+Z` / `Ctrl+Y` (`Ctrl+Shift+Z` أيضاً).
  كل إيماءة سحب/تحجيم = خطوة تراجع واحدة.
- **مسح الشريحة**: زر سلة المهملات يزيل كل معدات الشريحة (قابل للتراجع).
- `Esc` يغلق اللوحة. إغلاقها = وضع تقديم: الصور تبقى بلا مقابض وبلا
  اعتراض للنقر، وتظهر كذلك في معاينتي نافذة المعلم.

## التخزين والإحداثيات

- تُحفظ العناصر في `localStorage` بالمفتاح `db-equipment-v1` (نمط السبورة
  نفسه)، **بمفتاح `slide.id` الثابت** لا بفهرس الشريحة، فتبقى بعد التنقل
  بين الشرائح وبعد إعادة تحميل العرض.
- كل الإحداثيات كسور (0..1) من أبعاد الشريحة: `x` اليسار، `y` الأعلى،
  `w` العرض — والارتفاع يشتق من نسبة الأصل وأبعاد الشريحة. لذلك يبقى
  الموضع والحجم صحيحين عند تغيير حجم العارض أو التكبير، وجاهزين لأي
  تصدير مستقبلي.
- الحفظ مؤجّل 400ms بعد آخر تعديل + حفظ فوري عند مغادرة الصفحة.
- إضافة أصول جديدة لا تُغيّر صيغة الحفظ (`version: 1`)، ولا تعيد ترقيم
  `assetId` القائم، فالعناصر القديمة تُستعاد كما هي.

## التصدير إلى PowerPoint

المشروع **لا يدعم حالياً تصدير PowerPoint** (لا مكتبة تصدير مثبتة)، لذا
لا يوجد تصدير تُختبر فيه العناصر. نموذج البيانات جاهز للتصدير إن أُضيف
لاحقاً: إحداثيات نسبية × أبعاد الشريحة الهدف، وصور PNG محلية مجمّعة مع
الحزمة (ليست روابط خارجية تُحمّل وقت العرض).

## الأصول وترخيصها

**65 صورة أصلية** رسمت لهذا المستودع (لا صور من بحث الصور ولا أعمال طرف
ثالث): مصادر SVG في `src/equipment/assets/svg/` ونواتج PNG شفافة 512×512
في `src/equipment/assets/png/` (≈2.3MB إجمالاً، وأكبر ملف أقل من 80KB).
التفاصيل في `src/equipment/assets/LICENSE.md`. إعادة التوليد بعد تعديل أي
SVG:

```bash
npm install --no-save --no-package-lock @resvg/resvg-js
node scripts/generate-equipment-assets.mjs
```

`@resvg/resvg-js` أداة توليد مؤقتة فقط: ليست اعتماداً في `package.json`،
ولا يحتاج البناء ولا الاختبار إليها لأن PNG مولّدة وملتزمة في المستودع.

## إضافة أصل جديد (وصفة قصيرة)

1. ارسم SVG في `src/equipment/assets/svg/<id>.svg` بنمط الموجود
   (`viewBox="0 0 256 256"`، حدود `#1e293b` بسماكة 7، تدرّجات شفافة).
2. أضف PNG عبر `node scripts/generate-equipment-assets.mjs`.
3. أضف مدخلة في `catalog.ts`: `id` ثابت، اسم عربي، `category` قائمة،
   `keywords` عربية وفرنسية، `src` المحلي، `width/height: 512`.
4. حدّث `assets/LICENSE.md` وهذا الملف (العدد والفئة والمصدر إن وُجد).
5. شغّل `npm test` ثم `npm run check` — الاختبارات تتحقق من وجود SVG/PNG
   وأن PNG شفاف 512×512 وأن الأعداد مطابقة.
