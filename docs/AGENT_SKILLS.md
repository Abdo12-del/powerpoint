# جمع مهارات الوكلاء في هذا المشروع

لا يعتمد هذا المشروع على كتالوج `skills.md` أو حساب فيه. المهارات ملفات محلية بصيغة Agent Skills، ومكانها المشترك هو `.agents/skills/`؛ والرابط `.claude/skills` يشير إلى المجلد نفسه.

## إضافة مهارة من مستودع عام

تُستخدم أداة Vercel المفتوحة `skills` عبر `npx` دون تثبيت عالمي أو اعتماد دائم داخل التطبيق:

```bash
# اعرض ما يوفّره مستودع عام قبل الاختيار
npx skills add owner/repo --list

# انسخ مهارة مختارة إلى مجلد المشروع المشترك
npx skills add owner/repo --skill skill-name --agent universal --copy

# راجع حالة المهارات المثبتة وتحديثاتها
npx skills list
npx skills update skill-name
```

`--agent universal` يستهدف `.agents/skills/` في نطاق المشروع، و`--copy` يجعل نسخة المهارة ضمن ملفات المشروع بدلاً من ربطها بمجلد مؤقت. لا تستخدم `--all` تلقائياً؛ استعرض المستودع أولاً، ثم راجع `SKILL.md` والملفات المرفقة والترخيص قبل الإضافة. يتطلب CLI Node.js 22.20 أو أحدث، ويجلب المصدر مباشرة من GitHub؛ لا يتطلب تسجيل دخول إلى `skills.md`.

## المهارات المضافة حالياً

المصدر: [`vercel-labs/agent-skills`](https://github.com/vercel-labs/agent-skills)، والترخيص المعلن للمهارتين MIT. يسجل `skills-lock.json` المصدر وبصمة المحتوى.

- `vercel-composition-patterns`: أنماط تركيب React وتصميم واجهات المكونات، عند بناء مكونات قابلة لإعادة الاستخدام أو معالجة انتشار الخصائص المنطقية.
- `vercel-react-best-practices`: قواعد أداء React. طبّق ما يلائم React/Vite؛ تجاهل قواعد Next.js وReact Server Components والخادم أو الحزم غير المستخدمة.

لدينا بالفعل مهارات محلية متخصصة للحركة، الرسوم، الطباعة العربية، التوجيه الأكاديمي، وضمان الجودة؛ لا تضف مهارات متداخلة إلا عند وجود فجوة واضحة. بعض المستودعات الخارجية تتطلب جلب قواعد وقت الاستخدام من نطاق آخر؛ تحقق من إمكان الوصول إليه قبل اختيارها.
