# حزمة ملاحظات المعلم ومؤقت العرض (Presenter Notes & Timer)

حزمة جاهزة في القالب: `src/presenter/`. نموذج إضافة **Reveal Notes** المدمجة مع reveal.js (MIT): نافذة معلّم منفصلة تعرض للمعلم فقط — معاينة حقيقية للشريحة الحالية **والتالية**، ملاحظات الشرح، مؤقتاً للوقت المنقضي وساعة حائط — بينما تبقى واجهة الطلاب نظيفة تماماً (لا ملاحظات، لا عدّادات، لا شارات).

**المبدأ (من Reveal Notes):** `window.open` نافذة فارغة ثم تجهيز مستندها بالكامل وتركيب React داخله عبر `createRoot`، مع حلقة مزامنة بعد كل رسم تنقل الشاشة الحالية والتالية والملاحظات. لو حُجبت النوافذ المنبثقة، تُعرض اللوحة نفسها **مدمجة** فوق العرض (بديل لا يعطّل الدرس).

- **المختبر:** `/?lab=presenter` (وكذلك `?lab=notes`)
- **المفاتيح:** `N` (أو `ى`) فتح/تركيز/إغلاق — `Esc` يغلق — داخل نافذة المعلم: `→`/مسافة سابق، `←` تالٍ، `Esc` إغلاق (اتجاه RTL)
- **شريط التحكم:** زر 🎓 «نافذة المعلم» يظهر دائماً

## أين تُكتب الملاحظات؟

خاصية `notes?: string` على أربع عقد في `types/presentation.ts` — تقرأها `notesFor(screen, data, slides)` حسب نوع الشاشة:

| العقدة | الشاشة | مثال |
|---|---|---|
| `meta.notes` | العنوان | «رحّب بالحضور واذكر الخطة الزمنية» |
| `preface[i].notes` | خطوات المقدمة | «توقف هنا ثانيتين — دع الرقم يتحدث» |
| `slides[i].notes` | شرائح الفصول | «أشر إلى الرسم قبل قراءة الأرقام» |
| `final.notes` | الخاتمة | «افتح باب الأسئلة واذكر المراجع» |

خريطة وشاشة العنوان بلا ملاحظات تُرجع `''` فتظهر التلميحة «بلا ملاحظات لهذه الشاشة» — القالب الأبيض.

## المكوّنات

| أداة | الدور |
|---|---|
| `usePresenterNotes` — عبر `handlers.presenter` (المفتاح `N`) | فتح النافذة المنبثقة أو اللوحة المدمجة عند الحجب، والتركيز عليها إن كانت مفتوحة |
| `<PresenterWindow />` | نافذة/لوحة المعلم: معاينتان حقيقيتان بمقياس `width/1280` ومنشأ `top right` (RTL)، ملاحظات، مؤقت، عدّاد، شريط تقدم، أزرار تنقّل |
| `PresenterTimer` + `formatElapsed` + `wallClock` | منطق المؤقت النقي: start/pause/reset مع جمع الفترات، تنسيق `MM:SS` و`H:MM:SS` فوق الساعة، ساعة حائط `HH:MM` |
| `notesFor` / `screenInfo` / `slidesOf` / `slideById` | قراءة الملاحظات لأي شاشة، معلومات العدّاد «الشريحة i+1 / n» والعنوان والفصل، تسطيح الشرائح والبحث بالمعرّف |

## بنية نافذة المعلم

```
┌─────────────────────────────────────────────┐
│ 🎓 نافذة المعلم   03:25 ⏸ ↺   09:41   [×] │  ← مؤقت + ساعة حائط
│ ┌───────────────────┐ ┌──────────┐          │
│ │ معاينة حالية      │ │ التالية  │  العدّاد │  ← مصيّرتان حقيقيتان (لا صور)
│ │ 1280×720 → 620px  │ │ → 300px  │          │
│ └───────────────────┘ └──────────┘          │
│ ملاحظات المُقدِّم (whitespace-pre-wrap)      │  ← للمعلم فقط
│ ─────────────────────────────────────────   │
│ «رحّب بالحضور واذكر الخطة الزمنية…»          │
│ [◀ السابق]  ━━━━━━ progress ━━━ [التالي ▶] │
└─────────────────────────────────────────────┘
```

- المعاينتان حقيقيتان: نفس `TitleScreen`/`SlideScreen`/`FinalScreen` مصيّرة كاملة ثم مصغّرة (`transform: scale`) — لا لقطات ولا صور.
- المؤقت يتحدّث كل `TIMER_TICK_MS = 500ms` ويبدأ تلقائياً مع فتح النافذة، ويستمر عبر إعادة الرسم (refs لا state).
- شارة «الملاحظات مخفية عن الطلاب» تذكير دائم داخل النافذة نفسها.

## الخصوصية: كيف تبقى الملاحظات مخفية؟

1. **الواجهة الرئيسية لا تقرأها إطلاقاً** — `notesFor` مستدعاة فقط في مكانَي نافذة المعلم (popup render + اللوحة المدمجة)، ولا يمرّ أي نص ملاحظات إلى شجرة الطلاب.
2. الاختبارات تتحقق سلباً: `container.textContent` لا يحتوي نص الملاحظة عندما تكون النافذة مغلقة.
3. النافذة المنبثقة مستند مستقل (`about:blank`) — لقطة شاشة أو إسقاط «الشاشة فقط» لن يُظهر شيئاً.

> **نصيحة عرض:** اسحب نافذة المعلم إلى شاشتك الثانية واستعرض النافذة الرئيسية عبر البروجكتور — نفس أسلوب PowerPoint/reveal.js.

## قواعد الاندماج في Presentation.tsx

1. **`window.open` قد تعيد `null`** (حاجز نوافذ منبثقة) → التراجع إلى اللوحة المدمجة `variant="embedded"` — لا يفشل الدرس أبداً.
2. **أنماط النافذة المنبثقة** تُستنسخ من الصفحة (`style, link[rel="stylesheet"]`) + اتجاه `rtl` ولغة `ar` على مستندها.
3. **حلقة المزامنة بلا اعتماديات** (`useEffect` بلا مصفوفة): يرسم بعد كل تحديث للعرض حتى تبقى المعاينات والملاحظات متزامنة مع الشاشة الحالية.
4. **التنظيف:** `pagehide` + مؤشر `closed` كل ثانية + unmount عند إلغاء تركيب العرض — لا تسريب جذور React ولا نوافذ يتيمة.
5. **سلسلة Esc** تبدأ بنافذة المعلم: نافذة المعلم ← سبورة ← ليزر ← تسليط ← تكبير ← الاعتيادي.
6. **عقد التحكم §6 محفوظة** — المفتاح `N` إضافة خالصة: لا يغير السلوكيات القائمة، وتظهر في نافذة الاختصارات (`?`).

## مختبر `?lab=presenter`

لوحة مستقلة تشرح الحزمة وتعرض نافذة المعلم **مدمجة** فوق عرض عربي نموذجي كامل (عنوان + مقدمة بخطوتين + فصل بشريحتين + خاتمة) بملاحظات مكتوبة على كل عقدة، مع زرّي تنقّل يوضحان المزامنة الحية: الملاحظات والمعاينات والعدّاد تتغير مع الشاشة.
