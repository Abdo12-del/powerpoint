# أصول الوسائط المحلية

تُخدم الملفات في هذا المجلد عبر `/media/...` ويحل `resolveMediaUrl()` مسار النشر `BASE_URL` تلقائياً. استخدم أسماء وصفية، وفضّل `images/` أو `screens/` و`posters/` و`video/` عند إضافة أصول حقيقية. يحتوي `lab/` على رسوم SVG خفيفة لمختبر `/?lab=media`.

## ميزانية الحجم

- صور WebP/AVIF/JPEG: الهدف ≤250KB، ولا تتجاوز 500KB للصورة الواحدة. إجمالي صور الشريحة ≤1MB.
- SVG: ≤100KB، بلا صور Base64 مضمّنة أو بيانات تحرير غير لازمة.
- فيديو محلي: MP4/H.264، حتى 20 ثانية و≤5MB في Git. استخدم YouTube/CDN للفيديو الأطول أو الأكبر.
- ملصق الفيديو ≤100KB؛ و`blurDataURL` ≤1KB.
- لا تضف ملفات وسائط >1MB إلى Git إلا فيديو ضرورياً يبقى ضمن سقف 5MB.

أضف `alt` عربياً وصفياً، وحدد `aspectRatio` أو أبعاد الصورة لتجنّب قفز التخطيط. التفاصيل البرمجية وسلوك نشاط الفيديو: [`docs/MEDIA.md`](../../docs/MEDIA.md).
