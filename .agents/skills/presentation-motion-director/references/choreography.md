# ستوريبورد الحركة (Choreography) لكل شاشة

رموز التوقيت المعتمدة في القالب (`src/components/ui/motion.ts`):

| الرمز | القيمة | الاستعمال |
|---|---|---|
| `fadeUp` | y: 16 → 0، opacity 0 → 1، 0.5 ث، `easeOut` | دخول الكتل |
| `popIn` | scale 0.9 → 1، 0.4 ث | الشارات والأرقام |
| `staggerContainer(stagger, delayChildren)` | 0.08 / 0.1 افتراضياً | أي قائمة |
| `screenVariants` | انتقال الشاشة (x ± 40، 0.45 ث) | يُدار تلقائياً |

الـ easing الموحّد: `power3.out` في GSAP ≈ `[0.22, 1, 0.36, 1]` في framer-motion. لا تخلط easing «مرح» (`back`, `elastic`) إلا في عنصر واحد صغير (شارة، أيقونة).

---

## شاشة العنوان (≈ 2.0 ث حتى الاستقرار)

| الزمن | ما يحدث | الأداة |
|---|---|---|
| 0.0 | الخلفية حاضرة فوراً (جسيمات/نمط) — لا تدخل متحركة | `meta.background` أو `<DotPattern/>` |
| 0.1 | سطور الجهة الرسمية تظهر تباعاً | stagger (موجود) |
| 0.4 | شارة نوع العمل | `popIn` |
| 0.6 | العنوان كلمةً كلمة | `WordReveal` أو `TextAnimate by="word" animation="blurInUp"` |
| 1.2 | المنجزون / المشرف | `fadeUp` |
| 1.6 | زر البدء مع نبض خفيف | موجود (`animate-ping`) — أو `ShimmerButton` |

**لا تضف**: قصاصات، آلة كاتبة للعنوان (بطيئة)، أكثر من خلفية واحدة.

## المقدمة (كل خطوة ≈ 1.0 ث)

- الخطوة = عنوان + جسم. العنوان `WordReveal`، الجسم stagger.
- **الإشكالية** هي الاستثناء: السؤال يُكتب بـ `Typewriter` (سرعة 60–70؛ جملة من 10–14 كلمة ≈ 3 ث) ثم `Annotate type="circle" delay={3200}` حول المصطلح المحوري.
- الأهداف: 3–5 بطاقات `AnimatedList` أو stagger عادي.

## الخريطة

- stagger بطاقات الفصول (موجود). الفصل الحالي يُبرَز بالحدود لا بالحركة.
- مسموح: `TiltCard` حول البطاقات. ممنوع: خلفيات متحركة (تشتّت أثناء التنقل).

## الشريحة العادية (≈ 1.2 ث)

| الزمن | ما يحدث |
|---|---|
| 0.0 | رأس الشريحة (أيقونة + عنوان) يظهر مع الشاشة |
| 0.2 | المحتوى يبدأ stagger (0.08 ث بين العناصر) |
| 0.6–0.8 | المؤثر المهيمن يبدأ (beam، عدّاد، رسم خط، typing) |
| ≤ 1.5 | كل شيء مستقر؛ المؤثرات المستمرة (إن وجدت) هادئة |

قاعدة الـ `delay`: المؤثر المهيمن يبدأ بعد آخر عنصر stagger ≈ `0.2 + n × 0.08 + 0.3`.

## تمهيد الفصل / خلاصة الفصل

- التمهيد: عنوان الفصل `WordReveal` ثم مخطط المحاور `GsapReveal stagger={0.1}`؛ خلفية اختيارية `ParticlesBackground preset="network" density={0.5}` بلون الفصل.
- الخلاصة: stagger فقط. هذه شريحة تثبيت لا إبهار.

## الخاتمة

- الجمل الثلاث–الأربع تظهر بـ `WordReveal` متتابع (كل جملة بعد الأخرى بـ 0.6 ث).
- `celebrate` يُطلق القصاصات بعد 0.7 ث من الدخول — مرة واحدة. للمناقشة الرسمية `celebrate: false`.

## أنماط الدخول حسب الاتجاه (RTL)

| المعنى | framer-motion | GSAP |
|---|---|---|
| من اليمين (بداية القراءة) | `initial={{ x: 24 }}` | `gsap.from(el, { x: 24 })` |
| من اليسار (نهاية القراءة) | `initial={{ x: -24 }}` | `{ x: -24 }` |
| من الأسفل (محايد — الأكثر أماناً) | `{ y: 16 }` | `{ y: 16 }` |

عند الشك استعمل الإزاحة الرأسية؛ فهي صحيحة في الاتجاهين.

## ميزانية الحركة لكل شريحة (Motion Budget)

- عناصر متحركة عند الدخول: ≤ 12 (بعدها يصبح stagger مملاً — جمّع العناصر في مجموعات).
- مؤثر مستمر: ≤ 1 (جسيمات **أو** marquee **أو** orbit).
- canvas نشط: ≤ 1.
- مدة الدخول الكلية: ≤ 1.5 ث. استثناء وحيد: الآلة الكاتبة لسؤال الإشكالية (≤ 4 ث).
