# ترخيص أصول المعدات العلمية

جميع الرسومات في هذا المجلد **أصول أصلية أُنشئت خصيصاً لهذا المستودع**:

- `svg/` — **65 مصدر SVG** رسمت يدوياً لمشروع القالب، بنمط موحّد
  (`viewBox="0 0 256 256"`، حدود زرقاء داكنة، تدرّجات زجاجية/معدنية شفافة):
  - **الأصول العامة (10):** دورق مخروطي، مخبار مدرّج، كأس زجاجي، أنبوب اختبار،
    حامل أنابيب، ماصة قطارة، طبق بتري، مجهر، نظارات واقية، مصباح كحولي.
  - **الكيمياء (15):** سحاحة، دورق حجمي، دورق كروي، قمع فصل، مكثف ليبيغ، قمع
    ترشيح، زجاجة ساعة، بوتقة، هاون ومدقة، موقد بنسن، حامل ثلاثي وشبكة، ميزان
    تحليلي، مقياس pH، مقلب مغناطيسي، قضيب تحريك.
  - **الفيزياء (14):** عدسة محدبة، عدسة مقعرة، منشور زجاجي، نابض، بندول،
    أثقال مدرّجة، قدمة ذات الورنية، ملتيمتر، راسم اهتزاز، مغناطيس، شوكة
    رنانة، مقياس حرارة، ساعة إيقاف، منبع جهد.
  - **الأحياء (10):** شريحة مجهرية، ماصة دقيقة، حلقة زرع، أدوات تشريح، جهاز
    طرد مركزي، أوتوكلاف، حاضنة، لولب DNA، نموذج خلية، أنبوب دقيق.
  - **الجيولوجيا (7):** مطرقة جيولوجية، عدسة يدوية، بوصلة جيولوجية، عينة
    صخرية، بلورة معدنية، أحفورة، منخل.
  - **الصحة (9):** سماعة طبية، حقنة، جهاز ضغط الدم، أنبوب دم، أقراص، كبسولة،
    قفازات طبية، كمامة، نموذج قلب.
- `png/` — **65 ناتج PNG** شفافة 512×512 مشتقة آلياً من مصادر SVG عبر
  `scripts/generate-equipment-assets.mjs` (أداة التوليد `@resvg/resvg-js`
  تُثبَّت مؤقتاً عند إعادة التوليد فقط، وليست اعتماداً للمشروع). الحجم
  الإجمالي ≈2.3MB، وأكبر ملف أقل من 80KB.

لا تتضمن هذه الأصول أي عمل طرف ثالث، ولا صوراً من بحث الصور، ولا خطوطاً أو
أيقونات خارجية، ولا تتطلب نسباً خارجياً. تُستخدم وتُعدَّل وتُوزَّع بحرية ضمن
هذا المشروع ومشتقاته بالشروط نفسها التي يسير عليها المستودع.

الأسماء العربية والكلمات المفتاحية الفرنسية في الكتالوج وصفٌ وظيفي للمعدة
التعليمية، وليست اقتباساً من مرجع محمي؛ انظر `docs/SCIENCE_EQUIPMENT.md`
لقائمة المصادر المختصرة وحدود الاستدلال.

إعادة التوليد بعد تعديل أي SVG:

```bash
npm install --no-save --no-package-lock @resvg/resvg-js
node scripts/generate-equipment-assets.mjs
```
