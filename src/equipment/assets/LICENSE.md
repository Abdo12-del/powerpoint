# ترخيص أصول المعدات العلمية

جميع الرسومات في هذا المجلد **أصول أصلية أُنشئت خصيصاً لهذا المستودع**:

- `svg/` — عشرة مصادر SVG رسمت يدوياً لمشروع القالب (قوارير، مخابير، كأس،
  أنابيب اختبار وحاملها، ماصة قطارة، طبق بتري، مجهر، نظارات واقية، مصباح كحولي).
- `png/` — نواتج PNG شفافة 512×512 مشتقة آلياً من مصادر SVG عبر
  `scripts/generate-equipment-assets.mjs` (أداة التوليد `@resvg/resvg-js`
  تُثبَّت مؤقتاً عند إعادة التوليد فقط، وليست اعتماداً للمشروع).

لا تتضمن هذه الأصول أي عمل طرف ثالث، ولا صوراً من بحث الصور، ولا تتطلب
نسباً خارجياً. تُستخدم وتُعدَّل وتُوزَّع بحرية ضمن هذا المشروع ومشتقاته
بالشروط نفسها التي يسير عليها المستودع.

إعادة التوليد بعد تعديل أي SVG:

```bash
npm install --no-save --no-package-lock @resvg/resvg-js
node scripts/generate-equipment-assets.mjs
```
